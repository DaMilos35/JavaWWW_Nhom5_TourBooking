## 🎯 Hướng dẫn trình chiếu Slide Reveal.js (`index.html`):

Khi mở file `index.html` trên trình duyệt:
- **Phím `F`**: Bật chế độ trình chiếu toàn màn hình (Fullscreen).
- **Phím `Mũi tên Trái / Phải` (hoặc `Phím cách / Space`)**: Chuyển slide kế tiếp / quay lại slide trước.
- **Phím `ESC`**: Xem toàn cảnh lưới tất cả các slide (Overview mode).
- **Phím `S`**: Mở cửa sổ **Speaker Notes** (Cửa sổ bí mật hiển thị thời gian bấm giờ và kịch bản gợi ý cho người nói trên màn hình phụ).
- **Phím `B`**: Tạm thời tắt đen màn hình khi cần hướng sự chú ý của Hội đồng vào demo web.
- **In sang PDF**: Nhấn `Ctrl + P` trên Chrome để in slide ra bản in PDF nộp cho Giảng viên.

## 📊 Hướng dẫn xuất sang PowerPoint (.pptx) với Marp:
1. Cài Extension **Marp for VS Code** trên Visual Studio Code.
2. Mở file `VECTOR_DATABASE_SLIDES.marp.md`.
3. Bấm vào biểu tượng Marp ở góc trên bên phải thanh công cụ VS Code $\rightarrow$ Chọn **Export Slide Deck...** $\rightarrow$ Chọn định dạng **PowerPoint document (*.pptx)** hoặc **PDF**.
